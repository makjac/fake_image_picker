# fake_image_picker example

A minimal Flutter demo application for the `fake_image_picker` package.

The app uses the real [`image_picker`](https://pub.dev/packages/image_picker)
API. When you run it on a device it uses the native picker; when you run the
widget tests, `fake_image_picker` supplies deterministic fake responses.

## Run

```bash
flutter run
```

## Test

```bash
flutter test
```
